# Divine support information

Divine is independently branded from DeepSeek Harness and is not endorsed or supported by DeepSeek AI. The intended public distribution repository is [K4GEAe/Divine.AI](https://github.com/K4GEAe/Divine.AI). Its issue tracker, security reporting and support features must be verified at the time of publication. No dedicated support email address, support desk or service-level commitment has been confirmed.

To report an ordinary problem through a verified distribution channel, provide the installed version, operating system, relevant action, and a sanitized error description. In Desktop recovery, **Get diagnostic report** previews a sanitized support copy. Only **Export sanitized copy** writes a separate shareable file, and no report is uploaded automatically. The original local crash report can contain unredacted errors, file paths, terminal output and plugin details; never attach the raw report or post secrets, private files, payment information or project data to a public issue. Review any manual screenshots or attachments as well.

For vulnerability reporting see [SECURITY.md](SECURITY.md). For local-data handling and optional collection see [PRIVACY.md](PRIVACY.md). Licenses are in [LICENSE](LICENSE) and [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
